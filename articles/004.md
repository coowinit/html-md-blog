假设目前最后一篇文章是 `004.md`，下一篇文章直接创建：

```text
articles/005.md
```

Markdown 内容没有固定模板，可以直接写普通正文，也可以从 H1、H2、列表、代码块等任意标准 Markdown 内容开始。

## 第一步：新建 Markdown

例如创建：

```text
articles/005.md
```

正文可以这样写：

```markdown
这里直接开始正文，不需要第一行是 H1。

## 第一部分

正文内容。
```

## 第二步：修改 index.html

打开 `index.html`，找到：

```javascript
window.BLOG_POSTS = [
```

在数组最前面增加：

```javascript
{
  file: "005.md",
  date: "2026-08-15",
  title: "我的新文章"
},
```

数组中的顺序就是博客列表的显示顺序，不需要额外排序。

## 第三步：本地预览

VS Code 中使用 **Open with Live Server** 打开 `index.html` 即可。

这个版本不再使用：

- `build.mjs`
- Node.js
- `npm run build`
- `package.json`
- GitHub Actions workflow

因此修改 `index.html` 和 Markdown 后，刷新页面就可以看到结果。
