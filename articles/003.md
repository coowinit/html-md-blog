## 行内代码与代码块

修改 `window.BLOG_POSTS` 即可更新文章索引。

```javascript
window.BLOG_POSTS = [
  {
    file: "004.md",
    date: "2026-08-14",
    title: "后期如何新增一篇文章"
  }
];
```

代码很长时不强制折行，而是允许横向滚动：

```css
.markdown-body pre code {
  white-space: pre;
  overflow-wrap: normal;
}
```

## 表格

| 文件 | 是否日常修改 | 用途 | 说明 |
|---|---:|---|---|
| `index.html` | 是 | 文章索引 | 维护 file、date、title |
| `articles/NNN.md` | 是 | 文章正文 | Markdown 格式完全自由 |
| `css/style.css` | 否 | 页面样式 | 样式稳定后长期复用 |
| `js/app.js` | 否 | 页面逻辑 | 读取 Markdown 与 Drawer 交互 |

手机端表格宽度不足时可以横向滑动，不会把整个页面撑宽。
