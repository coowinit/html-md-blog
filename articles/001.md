欢迎来到这个极简的 HTML + Markdown 单页博客。

这里故意不使用一级标题作为第一行，用来说明：**Markdown 文件不需要遵守固定的开头格式**。

## 核心思路

整个页面只有一个文章列表。点击文章后，不跳转到新的 HTML 页面，而是从浏览器右侧滑入一个全屏阅读层。

文章信息由 `index.html` 中的数组维护，正文则单独保存在 `articles/` 目录。

## 文件职责

- `index.html`：维护文章文件名、日期和标题。
- `articles/*.md`：保存文章正文。
- `css/style.css`：负责博客与 Markdown 阅读排版。
- `js/app.js`：负责列表渲染、Markdown 加载与抽屉交互。

> 页面结构写好以后，日常更新只需要处理 `index.html` 与 Markdown 文件。
